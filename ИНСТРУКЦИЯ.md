# Инструкция по работе с проектом ExamHub

Этот проект представляет собой полностью интерактивный прототип веб-платформы подготовки к ЕГЭ/ОГЭ. Он построен на стандартных веб-технологиях (HTML5, CSS3, JavaScript ES6) без сложных сборок, что позволяет запускать и редактировать его на любом компьютере.

---

## 📦 1. Как передать проект другу

Весь проект находится в одной папке. Чтобы передать его:

1. Сделайте архив папки (кликните правой кнопкой мыши -> **Сжать «сайтик бахчасарай»** в macOS или **Отправить -> Сжатая ZIP-папка** в Windows).
2. Отправьте полученный `.zip` файл другу через любой мессенджер, почту или диск.
3. Ваш друг скачает архив, распакует его и сразу получит рабочую копию.

---

## 🚀 2. Инструкция по запуску

В корне папки созданы скрипты для автоматического запуска:

- **На macOS**: Дважды кликните по файлу `start.command` (он сам запустит локальный сервер и покажет сайт).
- **На Windows**: Дважды кликните по файлу `start.bat`.

Если запускать вручную через терминал:

```bash
# Перейдите в папку проекта и введите:
python3 -m http.server 8000
```

После этого откройте в браузере адрес: **http://localhost:8000**

---

## 🛠️ 3. Как редактировать проект

Проект имеет очень простую и чистую структуру. Любые изменения видны сразу после сохранения файлов и обновления страницы в браузере (F5).

- **Редактирование текстов / тестов / лекций**:
  Откройте файл `js/data.js` в любом текстовом редакторе (рекомендуется бесплатный **VS Code** или **Sublime Text**).
  Вся база данных хранится там в виде понятных списков. Вы можете легко изменить:
  - Тексты вопросов и пояснения в тестах.
  - Темы конспектов и их HTML-верстку.
  - Ссылки на видеолекции и их обложки.
- **Редактирование внешнего вида (дизайна)**:
  Все цвета, шрифты, отступы, анимации и стили находятся в файле `css/style.css`.
  В самом верху файла объявлены CSS-переменные (цвета кнопок, фонов, скругления границ), изменив которые, можно мгновенно перекрасить весь сайт в другой бренд-цвет.
- **Редактирование структуры страниц**:
  HTML-разметка всех экранов, менюшек и модальных окон находится в файле `index.html`.
- **Редактирование логики и интерактива**:
  Логика переключения страниц, симуляция тестов, генератор ИИ, поиск и уведомления прописаны в файле `js/app.js`.

## 🌐 4. Как выложить сайт в интернет (Деплой)

Поскольку сайт статический, его можно бесплатно и за 1 минуту опубликовать в сети:

1. **Netlify Drop (Самый простой способ)**:
   Перейдите на сайт [Netlify Drop](https://app.netlify.com/drop) и просто перетащите папку с проектом мышкой в окно браузера. Через 10 секунд вы получите рабочую публичную ссылку на сайт.
2. **Vercel**:
   Зарегистрируйтесь на [Vercel](https://vercel.com), нажмите **Add New -> Project** и перетащите папку.
3. **GitHub Pages**:
   Залейте проект в репозиторий на GitHub и в настройках (Settings -> Pages) укажите ветку `main` в качестве источника публикации.
