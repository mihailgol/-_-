# ExamHub — Веб-платформа подготовки к ЕГЭ и ОГЭ

ExamHub — это современная интерактивная образовательная платформа для подготовки выпускников к сдаче государственных экзаменов (ЕГЭ и ОГЭ) по Биологии и Химии. Интерфейс вдохновлен передовыми SaaS-продуктами (Stripe, Linear, Apple Human Interface) и адаптирован для работы на ПК, планшетах и мобильных телефонах.

---

## ✨ Основной функционал

1. **Интерактивные конспекты**:
   - Систематизированная база теории по темам экзаменов.
   - Парсер LaTeX-выражений для корректного и красивого рендеринга формул.
   - Система Premium-ограничений (Teaser Mode) для скрытия сложной теории под размытую заглушку с предложением подписки.
2. **Интерактивный банк тестов**:
   - Прохождение тематических опросов в формате ЕГЭ/ОГЭ.
   - Моментальная проверка ответов с цветовой подсветкой (зеленый/красный) и выводом разбора вопросов (Explanations).
   - Подсчет итогового процента выполнения с прогнозом реального балла ЕГЭ (по 100-балльной шкале).
3. **ИИ-генератор тестов**:
   - Генерация уникального теста по любой теме (световая фаза фотосинтеза, свойства алкенов и т. д.).
   - Реалистичная 4-фазная симуляция сборки вопросов ИИ.
4. **Медиа-плеер лекций**:
   - Интерактивное воспроизведение видеоуроков с поддержкой перемотки по таймлайну и живого подсчета времени просмотра.
5. **Динамический поиск и уведомления**:
   - Поиск по базе в реальном времени с выводом результатов (Notes & Videos) в выпадающий список.
   - Панель уведомлений с подсчетом новых сообщений и симуляцией прочтения.
6. **Полная адаптивность**:
   - Умное перестроение интерфейса: на экранах менее `600px` боковое меню скрывается, активируя нативный мобильный Bottom Nav Bar.

## 🛠️ Стек технологий

- **Backend**: Node.js 18+, Express, SQLite (`node:sqlite`), bcryptjs, cookie-сессии.
- **Frontend**: Чистый HTML5 (семантическая верстка, SVG-графика).
- **Стилизация**: Ванильный CSS (CSS Variables, CSS Grid, плавные переходы, анимации keyframes).
- **Логика**: Чистый JavaScript ES6+ (SPA, нативные ES-модули, клиентский роутинг с History API, интеграция с REST API).
- **Ресурсы**: Иконки Lucide, стоковая графика и обложки лекций с Unsplash API.
- **Тесты**: Vitest (unit), Playwright (E2E), ESLint + Prettier.

## 🚀 Локальный запуск

Требуется Node.js 18+.

```bash
npm install
npm run dev
```

Сайт будет доступен по адресу: **[http://localhost:8000](http://localhost:8000)**. Конфигурация через `.env` (шаблон — `.env.example`).

### Основные команды

```bash
npm run check        # Полная проверка: ESLint → валидатор → unit → E2E
npm run test         # Unit-тесты (Vitest)
npm run test:e2e     # E2E-тесты (Playwright, поднимает сервер с чистой БД)
```

## 🌐 Подготовка к Деплою

Бэкенд — обычное Node.js-приложение (Express). Для продакшена достаточно собрать статику фронтенда (или отдать её через Express, как делает `server/index.js`) и запустить:

```bash
NODE_ENV=production npm start
```

Рекомендуется запуск за обратным прокси (Nginx/Caddy) с HTTPS — тогда куки-сессии автоматически станут `Secure`.
