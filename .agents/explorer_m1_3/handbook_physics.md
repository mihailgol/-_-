```html
<h3>1. Кинематика материальной точки</h3>
<p><strong>Кинематика</strong> — раздел механики, изучающий движение тел без учета причин, вызывающих это движение. Основная задача кинематики — определить положение тела в любой момент времени.</p>
<h4>Основные понятия и уравнения движения</h4>
<ul>
  <li><strong>Материальная точка</strong> — тело, размерами которого можно пренебречь в условиях данной задачи.</li>
  <li><strong>Траектория</strong> — непрерывная линия, вдоль которой движется тело.</li>
  <li><strong>Путь (<em>l</em>)</strong> — длина траектории (скалярная величина, $l \ge 0$).</li>
  <li><strong>Перемещение (<em>s⃗</em>)</strong> — направленный отрезок (вектор), соединяющий начальное положение тела с его последующим положением.</li>
</ul>
<p><strong>Равноускоренное прямолинейное движение:</strong></p>
<ul>
  <li>Уравнение скорости: <em>v_x(t) = v_{0x} + a_x t</em></li>
  <li>Уравнение координаты: <em>x(t) = x_0 + v_{0x} t + (a_x t²)/2</em></li>
  <li>Формула без времени (связь перемещения и скоростей): <em>v_x² - v_{0x}² = 2 a_x s_x</em></li>
</ul>

<div class="note-info-box">
  <strong>Важные нюансы ЕГЭ/ОГЭ:</strong>
  <ul>
    <li>Отличие пути от перемещения: при движении по замкнутой траектории (например, один полный круг) перемещение равно нулю, а путь равен длине окружности <em>2πR</em>.</li>
    <li>При движении по окружности с постоянной по модулю скоростью центростремительное ускорение <em>a_{цс} = v²/R = ω²R</em> направлено к центру окружности и изменяет только направление вектора скорости.</li>
  </ul>
</div>

<h3>2. Динамика и Законы Ньютона</h3>
<p><strong>Динамика</strong> изучает причинные связи механического движения тел с их взаимодействием с другими телами.</p>
<ul>
  <li><strong>Первый закон Ньютона:</strong> Существуют инерциальные системы отсчета (ИСО), относительно которых изолированные тела сохраняют состояние покоя или равномерного прямолинейного движения.</li>
  <li><strong>Второй закон Ньютона:</strong> Ускорение тела прямо пропорционально равнодействующей всех сил, приложенных к телу, и обратно пропорционально его массе: <em>F⃗ = m a⃗</em>.</li>
  <li><strong>Третий закон Ньютона:</strong> Силы, с которыми два тела действуют друг на друга, равны по модулю и противоположны по направлению: <em>F⃗₁₂ = -F⃗₂₁</em>. Силы имеют одну физическую природу и приложены к разным телам.</li>
</ul>
<p><strong>Основные силы в механике:</strong></p>
<ul>
  <li><strong>Сила тяжести:</strong> <em>F_{тяж} = m g</em></li>
  <li><strong>Закон Всемирного тяготения:</strong> <em>F = G (m₁ m₂)/r²</em></li>
  <li><strong>Сила упругости (Закон Гука):</strong> <em>F_{упр} = -k x</em></li>
  <li><strong>Сила трения скольжения:</strong> <em>F_{тр} = μ N</em></li>
</ul>

<h3>3. Законы сохранения в механике</h3>
<p><strong>Импульс тела:</strong> векторная величина <em>p⃗ = m v⃗</em> (измеряется в кг·м/с).</p>
<p><strong>Закон сохранения импульса (ЗСИ):</strong> В замкнутой системе тел векторная сумма импульсов всех тел остается постоянной при любых взаимодействиях между ними: <em>∑ p⃗_{до} = ∑ p⃗_{после}</em>.</p>
<p><strong>Механическая работа:</strong> <em>A = F s cos α</em>. <strong>Мощность:</strong> <em>P = A/t = F v cos α</em>.</p>
<p><strong>Закон сохранения механической энергии (ЗСЭ):</strong> В замкнутой системе, в которой действуют только консервативные силы (сила тяжести, сила упругости), полная механическая энергия сохраняется: <em>E_{полн} = E_k + E_p = \text{const}</em>, где <em>E_k = (m v²)/2</em>, <em>E_p = m g h</em> (или <em>(k x²)/2</em>).</p>

<h3>1. Основные положения МКТ и идеальный газ</h3>
<p><strong>Молекулярно-кинетическая теория (МКТ)</strong> объясняет свойства вещества на основе его атомно-молекулярного строения.</p>
<h4>Три основных положения МКТ:</h4>
<ol>
  <li>Все вещества состоят из мельчайших частиц (атомов и молекул).</li>
  <li>Частицы вещества находятся в непрерывном хаотическом (тепловом) движении.</li>
  <li>Частицы взаимодействуют друг с другом силами притяжения и отталкивания.</li>
</ol>
<p><strong>Количество вещества (<em>ν</em>):</strong> <em>ν = N / N_A = m / M</em>, где <em>N_A ≈ 6,02 · 10²³ моль⁻¹</em> — постоянная Авогадро.</p>
<p><strong>Основное уравнение МКТ идеального газа:</strong></p>
<p><em>p = (1/3) n m₀ v̄² = n k T = (2/3) n Ē_k</em></p>
<p>Средняя кинетическая энергия поступательного движения молекул идеального газа напрямую связана с абсолютной температурой: <em>Ē_k = (3/2) k T</em>, где <em>k ≈ 1,38 · 10⁻²³ Дж/К</em> — постоянная Больцмана.</p>

<h3>2. Уравнение состояния идеального газа и изопроцессы</h3>
<p><strong>Уравнение Менделеева — Клапейрона:</strong> <em>p V = ν R T = (m / M) R T</em>, где <em>R ≈ 8,31 Дж/(моль·К)</em> — универсальная газовая постоянная.</p>

<div class="note-info-box">
  <strong>Изопроцессы в идеальном газе (при ν = const):</strong>
  <ul>
    <li><strong>Изотермический (T = const):</strong> Закон Бойля — Мариотта: <em>p V = const</em> (давление обратно пропорционально объему).</li>
    <li><strong>Изобарный (p = const):</strong> Закон Гей-Люссака: <em>V / T = const</em> (объем прямо пропорционален температуре).</li>
    <li><strong>Изохорный (V = const):</strong> Закон Шарля: <em>p / T = const</em> (давление прямо пропорционально температуре).</li>
  </ul>
</div>

<h3>3. Первое начало термодинамики и тепловые машины</h3>
<p><strong>Внутренняя энергия одноатомного идеального газа:</strong> <em>U = (3/2) ν R T = (3/2) p V</em>.</p>
<p><strong>Первое начало термодинамики:</strong> Количество теплоты <em>Q</em>, переданное системе, идет на изменение ее внутренней энергии <em>ΔU</em> и на совершение системой работы <em>A</em> против внешних сил:</p>
<p><em>Q = ΔU + A</em></p>
<p>При изобарном процессе работа газа равна <em>A = p ΔV</em>.</p>

<p><strong>КПД теплового двигателя:</strong> <em>η = A_{полезн} / Q₁ = (Q₁ - Q₂) / Q₁ = 1 - Q₂ / Q₁</em>, где <em>Q₁</em> — теплота от нагревателя, <em>Q₂</em> — теплота, отданная холодильнику.</p>
<p><strong>Максимальный КПД (Цикл Карно):</strong> <em>η_{Карно} = (T₁ - T₂) / T₁ = 1 - T₂ / T₁</em>.</p>
