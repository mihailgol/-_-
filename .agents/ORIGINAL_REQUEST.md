## 🎯 Requirements (Требования к системе)

### R1. Дизайн-система и вариантность оформления
Создание современного UI-дизайна платформы с поддержкой вариантов оформления (светлая/тёмная тема, премиум-акценты, микроанимации).

### R2. Социальная авторизация (VK ID + Yandex ID)
Подключение OAuth 2.0 авторизации через VK ID и Yandex ID на бэкенде с сохранением сессий в SQLite.

### R3. Интеграция с OpenRouter / DeepSeek API (ИИ-генератор)
Настоящая генерация заданий, разбор ответов учеников и составление персонального плана с помощью LLM API.

### R4. Режим «Пробники» и разграничение доступа (Free / Premium)
Создание симулятора реального экзамена с ограничением времени, разграничением базовых задач (Free) и полного банка задач (Premium).

### R5. Модуль Учителя / Репетитора
Конструктор кастомных тестов, генерация ссылок на ДЗ и сводный дашборд успеваемости учеников.
